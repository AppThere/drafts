# Fountain corpus

The feature-test files from the Fountain reference implementation,
<https://github.com/nyousefi/Fountain> (`FountainTests/`), unmodified. Copyright (c) 2012 Nima
Yousefi & John August, under the MIT licence in `LICENSE` beside this file.

Used by `FountainCorpusTest` for Phase 7's acceptance: "round-trip byte-identical on a corpus of
real `.fountain` files". Written by Fountain's authors to exercise Fountain, rather than by this
project to exercise its own parser.

The same repository's `Big Fish.fountain`, a full screenplay, is not included: it is John August's
script, and whether the software licence covers it is not something to assume. It round-trips
byte-identically too (checked 2026-10-05, outside the repository).
